# TaskDrop Sync Relay (Cloudflare Worker + WebSocket)

سرورلس رله برای همگام‌سازی ابری فوق‌سریع و بلادرنگ (Real-Time WebSocket) دیتابیس `TaskDrop` با رمزنگاری سرتاسری ۲۵۶ بیتی (E2EE).

## ویژگی‌ها:

- **بلادرنگ و آنی (Real-Time WebSocket):** تغییرات بدون کوچک‌ترین تاخیر بین تمام دستگاه‌ها پخش می‌شود.
- **صفر ریکوئست اضافه در پس‌زمینه (Zero Polling):** بدون هدر رفت اینترنت یا باتری.
- **۱۰۰٪ رایگان:** قابل اجرا روی پلن رایگان Cloudflare Workers.
- **امنیت کامل (E2EE):** تمام اطلاعات روی مرورگر شما رمز شده و سرور دسترسی به دیتای خام ندارد.

## مراحل راه‌اندازی (فقط ۱ بار):

۱. ورود به پوشه و ایجاد KV Namespace:

```bash
cd cloudflare
npx wrangler kv namespace create TASKDROP_VAULTS
```

این دستور یک `id` به شما می‌دهد. آن را در فایل `wrangler.jsonc` در بخش `id` قرار دهید.

۲. (اختیاری ولی توصیه می‌شود) تنظیم توکن امنیتی سرور برای جلوگیری از استفاده دیگران:

```bash
npx wrangler secret put AUTH_TOKEN
```

در پرامپت، یک کلمه عبور امن برای توکن سرور وارد کنید.

۳. دیپلوی با یک دستور:

```bash
npx wrangler deploy
```

پس از پایان، کلودفلر به شما آدرسی شبیه به این می‌دهد:
`https://taskdrop-sync-relay.YOUR_SUBDOMAIN.workers.dev`

این آدرس و توکن را در بخش **«همگام‌سازی ابری»** داخل اپلیکیشن `TaskDrop` وارد کنید!

## پروتکل سینک (نسخه ۲)

- هر تسک، یادداشت، گزارش و تنظیمات یک **رکورد رمزنگاری‌شده جدا** است که داخل SQLite یک Durable Object (`VaultV2`) نگه‌داری می‌شود. KV دیگر منبع اصلی داده نیست و فقط برای اپ‌های قدیمی و مهاجرت می‌ماند.
- ترتیب تغییرات را **سرور** با شمارندهٔ `seq` تعیین می‌کند، نه ساعت دستگاه‌ها. تعارض هر رکورد با ساعت منطقی ترکیبی (HLC) که لحظهٔ ویرایش ثبت می‌شود حل می‌شود، پس دستگاه قدیمی هرگز دادهٔ جدیدتر را بازنویسی نمی‌کند.
- هر دستگاه فقط رکوردهایی را می‌فرستد که خودش تغییر داده؛ سرور رکورد قدیمی‌تر را رد می‌کند و نسخهٔ برنده را برمی‌گرداند.
- tombstoneهای حذف بعد از ۳۰ روز پاک می‌شوند. دستگاهی که بیشتر از آن خاموش بوده خودکار یک همگام‌سازی کامل انجام می‌دهد.
- مسیرها: `POST /v2/api/:vaultId` و WebSocket روی `/v2/ws/:vaultId` (با Hibernation؛ اتصال بیکار هزینه ندارد).
- اپ‌های به‌روزنشده با پروتکل قدیمی (`/api/sync/...`) کار می‌کنند و اپ جدید تا وقتی یکی از آن‌ها فعال است (۱۴ روز اخیر نوشته باشد) با آن‌ها ادغام می‌کند.

### دیپلوی و مهاجرت

`wrangler deploy` خودش migration `v2` (کلاس `VaultV2`) را اعمال می‌کند. نیازی به کار دستی نیست؛ اولین دستگاه به‌روز‌شده داده‌های قدیمی vault را وارد پروتکل جدید می‌کند.

### تست روی Worker واقعی (محلی)

```bash
cd cloudflare && npx wrangler dev --local --port 8799
SYNC_E2E_URL=http://localhost:8799 vp test --run syncV2.e2e
```
